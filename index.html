Protección de datos

Identidad protegida desde el origen

  • Nombre, apellidos y DNI/NIE se cifran en el navegador.
  • GitHub no recibe ni almacena formularios.
  • Supabase conserva temporalmente un bloque cifrado.
  • La clave privada permanece en el servidor interno del SAE.

Protección del documento

El archivo se cifra mediante AES-256-GCM. La clave AES se protege con la clave pública RSA del SAE. Supabase solo recibe un binario cifrado.

Tamaño máximo: 12 MB. No incluyas datos personales en el nombre del archivo.
